# Sync Protocol v1

* 状态：Accepted for MVP
* 日期：2026-08-03

## Endpoints

```http
POST /v1/books/{bookId}/sync/push
GET  /v1/books/{bookId}/sync/pull?cursor={n}&limit={n}
POST /v1/books/{bookId}/sync/bootstrap
```

WebSocket（后续）：`{"type":"sync.available","bookId","cursor"}` — 仅唤醒。

## Push

Request:

```json
{
  "deviceId": "dev_01",
  "mutations": [
    {
      "mutationId": "0198...",
      "entityType": "transaction",
      "entityId": "0198...",
      "operation": "create",
      "baseVersion": 0,
      "schemaVersion": 1,
      "payload": {
        "description": "Lunch",
        "entries": [
          {"accountId": "acc_food", "amountMinor": "2500", "currency": "CNY"},
          {"accountId": "acc_cash", "amountMinor": "-2500", "currency": "CNY"}
        ]
      }
    }
  ]
}
```

分类也是账本账户，使用同一 Mutation 通道同步。客户端新增分类使用
`entityType=account`、`operation=create`，编辑分类使用 `operation=update`：

```json
{
  "entityType": "account",
  "entityId": "{bookId}:category_coffee",
  "operation": "create",
  "baseVersion": 0,
  "schemaVersion": 1,
  "payload": {
    "name": "Coffee",
    "accountType": "expense",
    "currency": "CNY"
  }
}
```

`entityId` 必须属于当前账本，`accountType` 支持 `income` 或 `expense`（以及
服务端已有的其他账户类型），名称会去除首尾空白并限制为 24 个字符。服务端
将分类变更写入 `sync_changes`，客户端 Pull/Bootstrap 时按账本 ID 重写本地
账户 ID，因此交易可以在分类 Mutation 之后引用新分类。

Rules:

- Batch 非大事务；每 Mutation 独立处理。
- 幂等键：`(bookId, deviceId, mutationId)` → 返回原 Receipt。
- 永久拒绝不阻止后续 Mutation。
- 业务数据 + Change Log + Receipt 原子（PG 模式）；内存模式等价顺序写。

Response:

```json
{
  "receipts": [
    {
      "mutationId": "0198...",
      "status": "applied|rejected",
      "resultCode": "OK|LEDGER_UNBALANCED|LEDGER_VERSION_CONFLICT|...",
      "entityVersion": 1
    }
  ]
}
```

## Pull

- `sequence > cursor`，正序。
- 默认 limit 500，最大 1000。
- 同一 `commitId` 不得跨页拆开。
- `nextCursor` = 本页最大 sequence。

## Bootstrap

1. 记录高水位 cursor。
2. 分页导出实体。
3. 客户端导入后从高水位 Pull。

Cursor 过期：

```json
{
  "code": "SYNC_CURSOR_EXPIRED",
  "bootstrapRequired": true
}
```

## 错误码（客户端只依赖 code）

| code | 含义 |
|------|------|
| OK | 成功 |
| LEDGER_UNBALANCED | 复式不平衡 |
| LEDGER_VERSION_CONFLICT | 版本冲突 |
| SYNC_CURSOR_EXPIRED | 需 Bootstrap |
| UNSUPPORTED_MUTATION | 暂不支持的操作 |
